# ცარიელი SAD → Export XML

## რატომ
ASYCUDA World-ის SAD-ს აქვს „Import XML File / Export XML File“ ღილაკები (UNCTAD დოკუმენტაცია). ქართული ეროვნული ველები და XSD საჯარო არ არის. ერთი ცარიელი ან საცდელი SAD-ის ექსპორტი შენი ანგარიშიდან გვაჩვენებს ზუსტ სქემას.

## ნაბიჯები
1. შედი eCustoms-ში საკუთარი დაშვებით.
2. გახსენი ახალი Detailed Declaration (SAD). შეავსე მინიმუმ ოფისი და ტიპი, ან დატოვე ცარიელი.
3. დააჭირე „Export XML File“ და შეინახე ფაილი.
4. ატვირთე ფაილი აქ. ის ინახება როგორც ნიმუში (sad_xml_sample) და გამოიყენება მხოლოდ სქემის შესადარებლად.
