# eCustoms დაშვება

## რა არის ეს
rs.ge-ს სერვისი „მონაცემთა საბაჟო ავტომატიზებულ სისტემა eCustoms-ში თავდაპირველად დაშვება“ (eservices.rs.ge, p=84). დაშვების შემდეგ შენი ორგანიზაცია თვითონ ავსებს და არეგისტრირებს დეკლარაციას ASYCUDA World-ში. დეკლარანტი იმპორტიორია (საბაჟო კოდექსი მ.6).

## ნაბიჯები
1. გაიანგარიშე, ღირს თუ არა: დაშვება 200 ₾ / 3 თვე, 300 ₾ / 6 თვე, 500 ₾ / 12 თვე (№96 გრ. 46). ბროკერი 100–150 ₾ დეკლარაციაზე. თავს იმართლებს ≈4–5+ დეკლარაციიდან წელიწადში.
2. დასაქმებული პირი უნდა იყოს დასაქმებულ პირთა რეესტრში. მეწარმე ფიზ. პირისთვის ან ახალი შპს-სთვის ეს დამატებითი ნაბიჯია rs.ge-ზე.
3. შეამოწმე, რომ საფასურის ბარათზე დავალიანება არ გაქვს.
4. განაცხადი შეავსე rs.ge-ს ავტორიზებული გვერდიდან. ველები: დასაქმებულის პირადი ნომერი, სახელი, საბაჟო ორგანოს კოდ(ებ)ი. პირად ნომერს აპში არ ვინახავთ.
5. პასუხი მოდის მოდულში და SMS-ით. შემდეგ აქვე მონიშნე „აქტიური“ და ვადა.
