# XML-ის შეტანა eCustoms-ში

## სანამ დაიწყებ
- XML „ექსპერიმენტულია“, სანამ შენი eCustoms-იდან ექსპორტირებულ რეალურ ნიმუშთან არ შედარდება. მთავარი გზა ველ-ველ ფურცელია.
- წინასწარი დეკლარაცია შეიძლება არაუადრეს 45 კალენდარული დღით ადრე. კურსი ფიქსირდება რეგისტრაციის დღით (მ.8).

## ნაბიჯები
1. შედი eCustoms-ში (ASYCUDA World) საკუთარი დაშვებით.
2. გახსენი ახალი SAD (Detailed Declaration).
3. „Import XML File“ ღილაკით ჩატვირთე ჩვენი XML. თუ ღილაკი არ ჩანს ან შეცდომას იძლევა, გადაწერე ველ-ველ ფურცლით.
4. შეადარე ყველა ველი ველ-ველ ფურცელს: ოფისი (A), ტიპი (1), იმპორტიორი (8), დეკლარანტი (14), Incoterm (20), ვალუტა/კურსი (22/23), HS (33), წონები (35/38), ღირებულება (46), გადასახდელები (47).
5. მიაბი დოკუმენტები (ინვოისი, ტრანსპორტი, შეფუთვის სია, სერტიფიკატები).
6. დაარეგისტრირე. ჩაწერე შეფასების ნომერი (A …) — დეკლარაცია დასრულებულია მხოლოდ მასთან ერთად.
